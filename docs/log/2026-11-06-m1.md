## Findings

1. **`spacetime build` does not type-check in this layout.** The CLI looks for `tsc` under `spacetimedb/node_modules` only; with npm workspaces everything is hoisted to the root, so it prints `tsc not found in node_modules. Make sure you have the typescript package as a dev-dependency and that your dependencies are installed.` and bundles anyway. The brief's "`spacetime build` catches a planted type error" held in the old single-package layout, not here. **Consequence:** `npm run typecheck` is the only type gate. The M2 publish script must run it before `spacetime publish`, and the M9 CI workflow runs it before the build. Recorded on the M2 row of `ROADMAP.md`.
2. **Bundler:** the CLI bundles with Rolldown, resolves tsconfig `paths` itself (so `@shared/*` and the type-only `@bindings/*` both work), needs no `spacetime.json`, and `spacetime generate` runs the same build first. Variant (a) of the §2.2 spike worked; no fallback needed, `rootDir: ".."` stays.
3. **Row-type helper for S3:** `spacetimedb/server` exports `Infer`; `type LobbyRow = Infer<typeof lobbyColumns>`. Optional columns come out as optional keys (`tournamentId?:`), whereas the generated bindings type them as required `T | undefined`, so a bindings `Lobby` is assignable to `LobbyRow` but not the reverse. `RowType` is not exported. Column `.default()` exists in `type_builders.d.ts` (relevant to the A36 auto-migration rule). The seven `@bindings/types` imports stay as they are (plan §2.3 calls the choice cosmetic).
4. **Line-ending churn:** `git ls-files --eol` shows the index is 100 % LF; the Windows checkout is CRLF (`core.autocrlf=true`) and every file written by a tool (`spacetime generate`, agents) is LF, so each generation made ~240 identical bindings files show as modified until a `git checkout --` and every commit prints dozens of "LF will be replaced by CRLF" warnings. Fixed in the follow-up commit with a `.gitattributes` (`* text=auto eol=lf`) and a worktree renormalization; no index content changes.
5. The sub-agent ran `git stash` by mistake and popped it back immediately; the orchestrator's uncommitted `ROADMAP.md` edit survived and every gate was re-run afterwards by the orchestrator.

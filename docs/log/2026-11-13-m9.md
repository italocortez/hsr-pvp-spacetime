## CI

Triggers: push to `main`, pull requests, manual. One job on `ubuntu-latest`, 15 minute limit, read-only token, no secrets. Steps: `npm ci`, `npm run typecheck`, `npm run lint:ci`, `npm test`, `npm run build -w web` (target `test`), `npm run check:patterns`. Every commit on `main` gets its own run; a newer push to a pull request cancels the older run.

Pattern gates: `subscribeToAllTables` in `web/src`; uncompiled custom media in the built CSS; `__devAuth` or router devtools in the build; Google Fonts addresses; the wipe flags outside the allow-list (`shared/stdb-targets.ts`, its test, three module files that name them in comments); test code or `.test.` file names in the build.

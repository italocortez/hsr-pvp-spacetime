# S10i — draft, cost set and rating rulings; Auction prices in the seed; server-side guest switches (2026-11-10)

## Goal

Implement the user's draft, cost set and rating rulings from the backend closing audit, and the two rulings that came up while doing so (Auction prices in the seed, the guest switches).

## Decisions implemented

- **A100**: `advance_stage` from Drafting is rejected until both teams hold all their characters.
- **A101 / A107**: every price comes from the lobby's own cost set, game mode and draft mode; completeness is settled at publish (missing-rows view, confirmation, confirmed gaps filled at 0 for the priced modes); a published set is patched in place under the same id, refused while a lobby on it is in a live match; an entry added later cannot be used until the set is patched; history keeps its stored costs.
- **A108**: the default cost set carries Auction prices equal to its Classic prices; no price default in any reducer.
- **A102**: `globalCompositeRating` per season.
- **A106**: a Classic timer auto-pick credits every player of the acting team.
- **A109**: guest creation breaker keeps the manual re-enable, default threshold 300, `server_set_guest_creation` and (user follow-up) `server_set_guest_lobby_creation`.

The "Where implemented" lines of rows A100, A101, A102, A106 and A107 say S10h; they landed here in S10i (rows are append-only and stay as written).

## Findings and hand-offs

- **The seed gap** (found by the implementer): the default set priced Classic only; the old silent defaults (a missing character row cost 0, light cones fell back to Classic rows) had hidden it. In Auction on the default set, a nomination's starting price is now the character's Classic price at eidolon 0 and the A61 / A64 eidolon extra applies for real.
- **Test fallout**: 322 tests failed because fixtures priced nothing; fixed at the fixture level (shared drivers price every name they use; the base harness seeds a minimal coverage row for the default set).
- **Residual, accepted as documented (review F5)**: a patch is allowed while a lobby is in AwaitingResult; an Admin edit of that closed game recomputes synergy surcharges from the current rows.
- **Review F6**: an Admin generic delete of a nominated character's cost row during a live Auction would make that nomination unsellable. Admin-only; left.
- The manual Drafting branch of `advance_stage` is reachable only through engineered state (comment added).
- **Open with the user**: ownership-based character stats (credit only players who own the character). Not implemented here; `playedCredit` is the single place to change.
- Synergy rows keep their explicit Auction modifiers of 0; the user was told.
- Deviations from a decision row: none.

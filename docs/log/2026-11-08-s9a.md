## Views as implemented

- **Masking** (`helpers/identity/anonymousHelpers.ts` `shouldAnonymize`, `helpers/identity/viewAnonymity.ts`): never the caller themself; staff (Moderator+) and the spectator referee (D-71) see every id; same team sees real identities (D-70); otherwise the target's seat kind decides: a spectator target is hidden under `isAnonymousSpectators`, a player / coach target under `isAnonymousPlayers` (fix pass, review #1); non-members (leavers, staff actors) are masked like members unless the caller is a spectator referee. Hidden rows carry `userId 0`, a seat label from `computeAnonymousLabel` (ordered by `joinSeq`, never derived from the id), no avatar / title, no audit ids; the fallback label is "<Side> player", never "Unknown".
- **Lobby.** `view_lobby_browser` (anonymous shared, re-created): one row per public or private lobby in Waiting / Drafting / Equipping / Scoring (S8e-V2; spectators may join a running match, A68(8)); no user id at all; `name`, or the label "Private lobby" for a nameless private lobby (never the code); `joinCode` only when `isPublic`; `hostLabel`, or "Anonymous host" when the host's own seat kind is anonymous; draft / game / match type, cost set name, team size, lineup format, counts, `maxSpectators`, stage. `view_my_lobbies`: the layer-0 row `{ id, joinCode, name, stage, isAway }` (away rows listed, abandoned dropped). `view_my_lobby`: the full `Lobby` row for members, host and audit ids 0 when hidden. `view_my_lobby_members`: PK `memberKey = lobbyId << 32 | joinSeq`; `{ lobbyId, joinSeq, userId | 0, label, lobbySlot, presence, isHost, isReferee, isCaptain, isConfirmed, avatarCharacterName?, displayedAchievementId?, mmrByMode?, accountRating?, accountCount? }`; `presence`: `abandonedAt` → Gone, `leftAt` → Away, `isOnline || hasLivePresence` → Online, else Offline; `mmrByMode` only when identified and `!hideMmr` (`EloConfig.initialRating` for an unplayed mode); `accountRating` / `accountCount` under OpenRoster / ClosedWithRating for everyone, under ClosedNoRating only to the player, teammates and the spectator referee; never `lastCursorAt` / `lastLineupAt`. `view_my_lobby_bans`: host / referee only; hidden bans read `bannedUserId 0` and "Banned player". `view_lobby_presets`: the system preset plus the caller's own. `view_my_lobby_chat`: System member events stored as `metadata { event, subjectUserId }` + a `{member}` template and rendered per reader (`helpers/lobby/memberEventChat.ts`); sender masking as before.
- **Match.** `view_my_match_session`; `view_my_match_result` (status, winner side, settled / concede fields; ids masked); `view_my_match_result_games` (game + nested group scores and adjustments, A60 flags and `closedAt`; adjustment `setById` masked); `view_my_lineups` (every lobby member sees both teams' live lineups with the per-game flags and closed marker: the `MatchLineup` table comment and A60's Why); `view_my_match_steps` (labels computed at read time; `actorUserId 0` when hidden); `view_my_match_participants` (+ `accountRatingSnapshot` per A40); `view_my_match_lineup_history` (A56; participated-only like the replay set); `view_admin_stuck_games` (Moderator+; Ranked lobby in Scoring, game open, exactly one ready flag, or both on an unresolved level-4 tie; `sinceAt` = the game row's `lastModifiedDate`). Removed: `view_match_history`, `view_match_participant_history`, `view_match_step_history`.
- **Tournament.** Arg views (`anonymousView`, `{ tournamentId }`, `isAnonymousDefault` governs): `view_tournament_participants` (Disqualified hidden, A26a(2); `Seat-<n>` by enrollment order counting DQ rows), `view_tournament_teams` (`captainUserId` only when not anonymous), `view_tournament_team_members`, `view_tournament_staff`. Per-sender: `view_my_tournament_enrollment` (own rows), `view_my_team_requests` (sent + targeting the caller's captained team; the requester's real id reaches the captain: open ruling), `view_my_stand_ins` (own and the caller's teams'; new `TournamentStandIn.user_id` index), `view_tournament_matches_for_me` (my team's Ready / Pending matches with the opponent's name and the colours via `matchSides`), `view_my_tournament_lobbies` (+ `blueTeamId` / `redTeamId`), `view_tournament_registrant_accounts` (+ `seat`; staff see ids, a participant their own rows, others' `userId` / `hsrAccountId` 0 in anonymous tournaments).

## Findings and deviations

1. **Anonymity leaks** (review #1, T-S9a 1–4): all fixed in the fix pass; A37 is binding, no ruling.
2. **Spectator host under `isAnonymousPlayers`**: the tests assumed hidden, the contract says identified; the tests were aligned (contract wins).
3. **Open ruling: team requests** (review #3, interpretation 10): keep the requester identified to the captain (recommended), or mask and let the captain accept by seat / request id.
4. **Open ruling: targeting members in an anonymous lobby** (review #4): kick, ban, unban, seat move, captain and referee transfer take a user id the host cannot see; recommendation: target by `joinSeq` (the member view's key), with `LobbyBan` recording the seat for unban, as a small S9c step with a decision row.
5. **Chat storage**: the private `ChatMessage.content` still carries the display name (the view re-renders per reader); only client-readable rows are A37's concern.
6. **Egress backlog** (review #5): the member and browser views re-evaluate on the 20 Hz cursor stamp rewrite of `LobbyMember`; moving the stamps off the row (S5 finding 2) is scheduled for the egress pass.
7. **Clear-publish**: the `refereeFullControl` column drop joins the S11 clear-publish list.
8. **Usage numbers** are the harness task-notification figures.

## Goal

Close the three questions S9a and S9b left to the user: an anonymized host or referee could not call the six member-targeting lobby reducers (they took a user id the caller cannot see); a referee seated on a team read the opponents' rosters and exact ratings under `ClosedNoRating`; a captain saw a team request with a real id but an anonymized label.

## Decisions implemented

**A73** (`view_my_team_requests` identifies the requester to the captain: real id and real name, every tournament; an A37 clarification), **A74** (the six reducers target by seat number, the server resolves the seat to the user id and runs the unchanged logic; `LobbyBan.bannedJoinSeq`; `Lobby.lastJoinSeq` so a seat number is never reused; the preventive ban of a non-member is gone; no user id in arguments or rejections), **A75** (D-14's referee exemption narrowed to the spectator referee).

## Rules as implemented

- **A74(1) seat targeting, one path.** `resolveSeat(ctx, lobbyId, joinSeq)` (`helpers/lobby/lobbyHelpers.ts`) returns the lobby's `LobbyMember` row with that `joinSeq` through `LobbyMember.lobby_id` or throws "No member sits at seat N of this lobby.". `kick_member`, `ban_member`, `set_captain` take `targetJoinSeq` and resolve it right after "Lobby not found."; `set_team_slot` takes an optional `targetJoinSeq` (omitted = the caller's own seat; a seat resolving to the caller is the self-move too); `transfer_referee` has no lobby lookup and resolves the seat after the caller's membership and referee checks. Every other line of the six bodies is unchanged and runs on the resolved user id (self / host guards, `canKickOrBan`, A68(6) stage rule, `removeMemberRow`, chat events, audit stamps, logs).
- **A74(2) bans.** `LobbyBan.bannedJoinSeq` (before the audit columns) records the seat the member held; `ban_member` requires a member row (present or away) and removes it like a kick; the "Ban Non-Member" preventive ban is gone. `unban_member(lobbyId, bannedJoinSeq)` finds the ban through `LobbyBan.lobby_id` ("No ban is recorded for seat N of this lobby.") and deletes `(lobbyId, bannedUserId)`; permission rule unchanged (A45(3)). `view_my_lobby_bans` and `view_admin_lobby_bans` carry `bannedJoinSeq`; the S9a masking of the banned user and the banner is untouched.
- **A74(3) seat numbers never reused.** `Lobby.lastJoinSeq` (before the audit columns): `create_lobby` and `create_tournament_lobby` write 1 with the host's row at `joinSeq: 1`; `nextJoinSeq(ctx, lobby)` returns `lastJoinSeq + 1` and `join_lobby` (its only caller now) writes it back inside the Lobby update it already makes; the `Math.max` scan over the members is gone. `view_my_lobby` and `view_my_tournament_lobbies` spread the Lobby columns and therefore carry `lastJoinSeq` (interpretation 2, about 4 bytes per row).
- **A74(4).** No argument or rejection text of the six reducers names a user id; the rejections cite the seat.
- **A75.** `view_my_roster_visibility`: `fullAccess = isSelf || (isReferee && Spectator) || sameTeam`; a seated referee follows self / teammate / `rosterVisibility`. `ratingVisible`, `hideUserId`, `shouldAnonymize` and `lobbyAnonymousFor` already used the spectator test; no other view or helper grants a seated referee more.
- **A73.** `view_my_team_requests`: a request by someone else targeting the caller's team carries the requester's real `userId` and real display name (`resolveUserLabel`) in every tournament; the caller's own rows keep the tournament-anonymity label.

1. **Guard order** (review #1): resolving the seat before the caller's own checks let a stranger map the occupied seat numbers from two rejection texts; fixed (lobby → caller checks → seat; `set_team_slot` gates a non-member with `ensureHostOrAbove` before resolving). 2. **`lastJoinSeq` on two lobby views** (interpretation 2, accepted): `view_my_lobby` and `view_my_tournament_lobbies` spread the Lobby columns; about 4 bytes per row; the egress pass may strip it.
3. **Preventive bans are gone** (A74(2)): a ban needs a seat (a present or away member); a user without a row is banned when they come back. "Ban Non-Member" is marked superseded.
4. **Test alignments** (T-S9c): three existing assertions followed the old rules (unban text, captain label, seated referee) and were aligned to A73 / A74 / A75 as the contracts now read.

# S14.3i: a shared information popover; the save spot becomes icon-only

**Date:** 2026-11-17 · **Step:** S14.3i (A210 items 6 to 8) · **Tests:** T-S14.3i

## Goal

One reusable information popover for every page (the mockups' info dot and info box), built now, and with it the team builder's save spot beside the loadout name becomes one icon and never any words, so the name field keeps its width whatever the save state does. Problems get a small pill that shows by itself. The Auction panel's two one-off info buttons move to the shared piece.

## The user's words (2026-11-17)

- "I'm thinking that the information icon can be a small popup when you hover over it so we stay with icons and dont change the width loadout name component after an edit. I remember the mockups have a pattern for the information hovers, we could create the reusable component now for those."
- "I would prefer the information icon to be the exclamation symbol that we created for autosaves, its nicier."
- "For problem states ... i think a small popup pill stating problems would work better."
- Agreed with the orchestrator: the pill shows by itself when a problem appears, goes away while the mark stays, comes back on hover, focus or tap; it floats and never covers the name; changed or deleted on another device and account full keep visible notices in the card; screen readers hear the reason when the problem appears, as before.

## Choices made here (for the user to rule on)

1. **Empty working loadout:** the quiet "!" with "Pick a character to start a loadout." in its pill (not a visible line, not a placeholder elsewhere). No blank spot, the hint kept, the width constant.
2. **Pill placement for the save spot:** above, end-aligned, 16px from the icon so it clears the name box; below would cover New Loadout and Copy link for five seconds.
3. **Pill look:** a capsule (14px radius on a 28px line), 0.75rem semibold snow text on the elevated surface; the warning pill adds a warning edge and a 12% warning tint. A rounded rectangle looked heavier beside a 20px icon.
4. **Short pill lines** (all invented, ★ in `pages.md`): the full reasons stay the name field's description and the announcement; a server's own text is not shown in the pill.
5. **Quiet states never pop up by themselves** (empty, not stored yet, loading): the account list loading on every member visit would otherwise pop a pill on each page load.
6. **The floppy's hover:** the shared brightening toned down to muted-to-body (not iris), `cursor: help`, no border or background.
7. **Click or tap is a toggle that pins:** on a hover- or focus-opened panel it pins it open (the guide's "show, not toggle" concern), a second press closes it.
8. **Script-driven hover and placement** instead of `interestfor` and CSS anchor positioning: both are Chromium only in this project's target (`interestfor` needs a polyfill, which needs approval); one path for Chromium and Firefox, testable as a pure function.
9. **A full list's notice row** (account full, browser or account full on a working loadout): new visible rows; before, those words sat beside the name.
10. **"Save status"** as the button name, and one more Tab stop in the name row (the brief asked for a real button).

## Goal

One vocabulary for the two databases at every layer (CLI, scripts, module, test harness, browser), no hand-typed database names, no legacy `.env.local` reading, a publish path that cannot wipe prod, and a bootstrap that mints a per-database delegate token instead of the old first-come `register_server`.

## Findings and deviations

1. **`ctx.env.STDB_TARGET` is typed `string`, not `'test' | 'prod'`**, on SDK 2.14.1 + TS 7.1β (`schema<H, const E extends EnvironmentSchema>(entries, { env })`, `ctx.env: EnvironmentFor<SchemaDef>`); at runtime an unset value reads `undefined`, so the default-deny guard holds. Re-check on the next SDK/TS bump.
2. **Enum inserts:** the sub-agent wrote `kind: { tag: 'Owner', value: {} } as any`; the orchestrator replaced it with the plain `{ tag: 'Owner' }` / `{ tag: 'Delegate' }` form (0 errors, bindings unchanged). Several `as any` casts remain from the old code (`server.ts`, `index.ts` pause events); S3's cleanup candidates.
3. **`spacetime describe --json` (2.14) returns `{ sections: [...] }`**, not top-level `tables[]`; the §C.5 schema-delta gate must diff the `Tables`/`Reducers`/`Views` sections. Noted for S11/S13.
4. **Bootstrap idempotency:** game data is upserted, achievements skipped by name (criteria not re-checked once an achievement exists), Elo/Rating config report "exists", GC job seeds are no-ops; **every run mints a new delegate and best-effort revokes the one recorded in `.env.<t>.local`** (`STDB_SERVER_IDENTITY`, an orchestrator addition to §C.4 so rotation leaves no orphan rows).
5. **Backup/restore scripts (A41a)** are not in M2: `server_restore_table` depends on the final schema; scheduled after S10 and before S13 (roadmap).
6. **Spine columns** still exist in the module until S3 (A17); the normalizers send `null`/`[]` for them from the Spine-free seed files.
7. 22 test files still mention the old token key in header comments; comment-only and the live suite is rewritten in S10.
8. Biome: the sub-agent formatted only its new files; `shared/stdb-targets.ts` stays verbatim (the repo-wide lint gate is M3).
9. `tools/` stays outside `typecheck` (`capture-ws-frames.ts` imports the unpinned `ws`).

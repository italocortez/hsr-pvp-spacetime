## Goal

## Decisions implemented

- **A77**: `User` is private; `UserPrivate` merged into it; staff read `view_admin_users`; `Leaderboard` carries name and avatar (denormalized columns, the option of A77(1) chosen by the implementer because a view would scan the table).
- **A143**: `TournamentPlayerAccount.origin` (Entry / StandIn) and a tournament index; stand-in locks released by origin. Addition beyond the row's wording: a StandIn lock that passes through an Entry path becomes Entry; an Entry lock is never downgraded.
- **A162**: a match event's creator needs the bracket permission to read its attendee list or edit it; an Admin reads every attendee list.
- **A163**: deleted users leave the leaderboard at once; match events of former staff go to the tournament organizer; maintenance mode admits Admins and blocks non-Admin reducers; lobby passwords are letters and digits, at most 20; the stale binding file deleted; publish with the scheduler guard.
- Triage items "fix at S11" (`notes/audit-2026-11-09/low-findings-triage.md`): L5, L6, L11, L12, L18, L19, L24, L39, L49, L60, L84 (two of four columns), L91, L92, L109, L110, L111 (2 placeholders turned into tests). Skipped: L58 (needs a live measurement). L9 was ruled in A163(3).

## Main changes

- Scheduler guard: `ensureScheduler` (`ctx.senderAuth.isInternal`) first in the five scheduled reducers.
- `LobbyCursorStamp` (new private table) replaces `LobbyMember.lastCursorAt`; cursors only in Drafting, Equipping, Scoring; chat stamps `lastActivityAt` at most once per 60 s.
- Lobby password: salted SHA-256 (hand-written, checked against the standard library on 3000 random inputs and all boundary lengths by the reviewer).
- `CostSet` private with `view_published_cost_sets`; indexed admin cost upserts; indexes `Leaderboard.season_id`, `MmrRating.season_id`.
- Removed: `ArrangeLineup` step variant, `MatchSessionStep.anonymousLabel`, `MatchResultGame.validationStatus` / `validatedByUserId`, `Tournament.seasonId`, `TournamentFinalizeJob.cursor`. Added: `MatchResultRecord.staffOverrideReason`.
- GC job re-arm by the manual tools (empty table or a long-overdue row); `stdb:guest-switch` script; season-aware `server_set_mmr`.
- Live tests (unexecuted until the test1 run): smoke cursor test starts a draft; the scheduler sensor sends encoded job rows; the private-table refusal is asserted specifically; nine outsider-isolation checks written.

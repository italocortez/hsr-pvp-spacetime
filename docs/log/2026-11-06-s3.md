## 6. `UserPresence`: one row per identity, not a connection count (A48, D-A1)

Chosen: **one row per identity** (`identity` PK, `userId` indexed, `isOnline`, `lastLoginAt`, `lastSeenAt`). "User online" = any row of that user with `isOnline = true`.

Why not a count:
1. **Drift.** A per-user counter is only correct if every `client_connected` is matched by exactly one `client_disconnected`. A host restart or module crash (the hook may or may not run for the connections that were open; SpacetimeDB documents no guarantee a module can rely on), a hook that throws mid-way, or a double dispatch leaves the count > 0 forever: the user shows online, `LobbyMember.isOnline` never flips, and the A22a referee transfer never fires. A per-identity row **self-heals**: the next connect or disconnect of that identity rewrites its own row, and identity GC deletes the row together with the identity (S4), so a stale row costs one wrong bit for one device until that device reconnects or ages out.
2. **2.10.2 session takeover.** A second connection on the same token runs the old connection's `client_disconnected`, then accepts the new one. With a count that is a −1/+1 pair whose order must be right; with a per-identity row both hooks touch the same row and the end state is `isOnline = true` whatever the interleaving. This is also the page-refresh case the 15-second grace (A22a) covers.
3. **It answers the admin question** ("which devices are online, last seen when") without a second table, and it gives `lastLoginAt` a home now that `User.lastLoginAt` is gone.

S4 contract (markers placed in `index.ts`, `auth.ts`, `server.ts`, `identityGc.ts`): `client_connected` upserts `{ identity: ctx.sender, userId, isOnline: true, lastLoginAt: now, lastSeenAt: now }` once the `UserIdentity` mapping exists (a fresh guest connects before `login_as_guest`, so `login_as_guest` also upserts the row), restores `LobbyMember.isOnline` (F1), deletes the pending `RefereeTransferCheck` via `by_lobby_and_user`, and rejects the socket under `AbuseConfig.maintenanceMode` (B-8). `client_disconnected` sets `isOnline = false, lastSeenAt = now` on the one row, and only when the user has **no other live row** marks the active-stage memberships offline (`disconnectedAt`) and inserts the `RefereeTransferCheck` 15 s out; the flag transfers and auto-pause move into `run_referee_transfer_check`. `run_identity_gc` deletes `UserPresence` rows with the identities it removes and treats "online" as any live row. `server_set_online` (test-only) forces every identity row of the user.

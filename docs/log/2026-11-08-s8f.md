## Goal

Make the membership lifecycle coherent after A67: a Leave during a live game is a disconnect the player can come back from, nobody is forfeited automatically, a leaver who takes another lobby gives the first one up knowingly, spectators and coaches are free the moment they leave, players are never removed from a running match by staff, a lobby with members always has a host and a referee, spectators may join while a match runs up to a per-lobby count, and the Waiting GC respects presence.

## Decisions implemented

A68(1) Leave = disconnect (shared `markMemberOffline`; D-31 auto-concede and D-38 rejoin ban removed); A68(2) `leftAt` away marker (`client_connected` never restores it; the 15 s check treats it as offline regardless of presence); A68(3) no automatic forfeit, away / abandoned rows count as offline players for `claim_forfeit`; A68(4) `abandonCurrentMatch` on `create_lobby` / `join_lobby` / `create_tournament_lobby`, `abandonedAt`, flags moved on abandon, the same test in `delete_my_account`, `view_my_lobbies` drops abandoned rows; A68(5) spectator / coach Leave deletes the row in every stage; A68(6) no kick / ban of players after `start_draft`, LMA cleanup on removals, `dq_participant` no longer kicks a player mid-match; A68(7) `transferFlagsOnRemoval` in A22(5) order online-first then any, on every removal including user deletion, `reclaim_referee` fills an empty flag, D-35 retired; A68(8) spectator joins in live stages up to `maxSpectators` (0–12, default 12) on `Lobby` / `LobbyPreset`, the count caps watchers only (orchestrator interpretation, below); A68(9) Waiting GC presence test. A68(10) views: `view_my_lobbies` only; member presence states are S9.

## Rules as implemented

- **Leave in a live stage** (`reducers/lobbyLifecycle.ts` `leave_lobby`, Drafting / Equipping / Scoring, player): `markMemberOffline` (`helpers/disconnectHelpers.ts`, shared with `client_disconnected`): `isOnline = false`, `disconnectedAt = now` under Standard / Deferred (never NoAction), one `RefereeTransferCheck` 15 s out, plus `leftAt = now`; row, `LobbyMemberAccount` rows and `currentPlayerCount` kept; system chat "… left the match."; a second Leave while away changes nothing (the forfeit clock keeps its first stamp). Spectators / coaches: row deleted in every stage. Waiting / AwaitingResult player leave: row deleted as before; every deletion runs `transferFlagsOnRemoval` first; an emptied Waiting lobby is hard-deleted.
- **Away rows** (`leftAt`): `client_connected` skips them, `client_disconnected` leaves them alone; the 15 s check (`run_referee_transfer_check`, pure core `decideRefereeTransfer`) treats `hasLeft` rows as offline whatever `hasLivePresence` says and never picks them; `decideAutoPause` treats an away player like a disconnected one. Return through `join_lobby`: clears `leftAt`, sets online, pool decrement and auto-resume as a reconnect, system chat "{name} is back."; an `abandonedAt` row → "You left this match for another lobby and cannot return."
- **Forfeit** (`isForfeitEligible`, `claim_forfeit`, `defer_match`, `isThirdPartyReferee`): away and abandoned rows are offline players with the Leave's `disconnectedAt`; grace / empty-pool logic unchanged; `performConcede` callers are `concede_match`, `claim_forfeit` and `dq_participant`'s whole-team path only.
- **Another lobby** (`helpers/lobbyHelpers.ts` `ensureNotInLobby(ctx, userId, abandonCurrentMatch)` / `membershipHold`): AwaitingResult rows and abandoned rows never count; an away row in a live lobby → "You left lobby {joinCode} mid-match. Joining here means you cannot return to it." without the flag; with it the flags still on that row move (`transferFlagsOnRemoval`, A22(5) online-first then any) and `abandonedAt` is written (`leftAt`, offline, `disconnectedAt` kept); any other membership → "You are already in a lobby. Leave it before creating or joining another." `delete_my_account`: same test. `view_my_lobbies` drops abandoned rows.
- **Removals** (`kick_member`, `ban_member`): Waiting / AwaitingResult any member (host excepted), row + LMA rows deleted, `LobbyBan` for a ban, flags transferred, counts updated; live stages only spectators / coaches, player target → "Players cannot be removed once the draft has started; the match ends by result, concede or forfeit." `dq_participant`: a single player's DQ touches no live lobby; the whole-team path (bracket settlement, force-concede with the team's colour, `writeMatchGames`) unchanged.
- **Flags** (`helpers/flagTransferHelpers.ts` `transferFlagsOnRemoval`, pure `pickSuccessor`): host → Blue players → Red players → spectators → coaches by `joinSeq`, online first then any remaining member, leaver and `hasLeft` rows excluded, captain restricted to the same team's players (left on the leaver's row when the team has no other player); runs on every row removal in every stage (leave, kick, ban, abandon, user deletion). In the 15 s check the host still moves only to an online member (A22a as before); `reclaim_referee` gives an unheld flag to any member who asks. D-35's lowest-user-id rule is gone (the only remaining `userId` sort is the tournament team captain transfer, D-21).
- **User deletion** (`helpers/userDeletionHelper.ts` `performUserDeletion`, A68(7)): flags moved, then the row removed like a leave (`removeMemberRow`) in Waiting / AwaitingResult and for spectators / coaches in every stage; a seated player in a live stage (admin-driven deletion) keeps the row as away + abandoned (`isOnline = false`, `leftAt`, `abandonedAt`, `disconnectedAt` under Standard / Deferred; existing stamps kept; no 15 s check since the flags already moved): an offline player for the forfeit test, never a candidate.
- **Spectator joins** (`join_lobby`): new joins accepted in Waiting / Drafting / Equipping / Scoring (Spectator slot in live stages; Waiting auto-seat as before), AwaitingResult closed; 20-member cap kept; `maxSpectators` counts **watchers only**: every live-stage join and, in Waiting, only a non-team joiner of a tournament lobby; a casual Waiting joiner is a seat candidate (D-27) and is not counted; "Spectator slots are full (max N)." `set_team_slot` into Spectator (Waiting only) follows the same rule. `maxSpectators` 0–12 ("maxSpectators must be between 0 and 12."), default 12 (system preset, `create_lobby`, preset creation; user, 2026-11-08: "set the default of spectators to 12"), free set for tournament lobbies (copied from the preset); the host sitting as spectator counts.
- **GC** (`reducers/lobbyGc.ts`): Waiting lobbies skip while any member is online (away / abandoned = offline) before the 30 min idle rule; live stages unchanged apart from the flag rename; AwaitingResult never GC'd.
- Import graph: no cycle (`memberPredicates.ts` has no imports; `lobbyHelpers` → `flagTransferHelpers` → `memberPredicates`).

## Deviations and judgment calls

1. **Plan §2.1 path error:** `components/types` does not exist at `471a481`; the three files live at `components/features/types/`. Imported from there.
2. **Duplicate bindings:** `spacetimedb/src/module_bindings` came along inside `spacetimedb/src`; removed before the import commit (plan: not imported). It was stale: `index.ts` and four `view_*_table.ts` differed from the kept copy. The kept `types.ts` has every name the module imports.
3. **`rootDir: ".."` kept in `spacetimedb/tsconfig.json`** (plan §2.2 said drop `rootDir`). TS 7 raises TS5011 without it because the type-only `@bindings/types` import makes the repo root the common source directory; set to the repo root it also avoids TS6059 once `shared/` is imported. Emission would land under `dist/spacetimedb/src/…`, so M1's `spacetime build` spike must confirm the CLI bundles from source (expected) rather than from `tsc` output.
4. **`@types/node 26.6.6`** instead of the old `20.19.37`: vitest 5.1.0's peer range is `^22 || >=24`, so `npm install` fails otherwise. Not in the §4.1 pin list → **user confirmation pending.** **Confirmed by the user 2026-11-06: keep 26.6.6.**
5. **`spacetimedb` pinned exactly to `2.6.1`.** The imported caret `^2.6.1` resolved to 2.14.1 on a fresh install, which would have folded part of M1 into M0. Clean install at 2.6.1 typechecks 0/0 on TS 7.1.0-beta, so the upgrade stays a deliberate M1 change. (Informative: the 2.6.1 bindings and module also typechecked clean against SDK 2.14.1 before the pin.)
6. **`typecheck` uses `--noEmit`** for the module: otherwise `tsc -p spacetimedb` emitted ~309 files into `spacetimedb/dist/` and one stray `web/src/module_bindings/types.js`.
7. **Task T-M0** (test files) was defined by the orchestrator, since the plan had no M0 test task but the M0 grep gate requires the old name gone from 11 test files. Edits are import paths and the one fallback string; S2's T-S2 replaces the fallbacks with the resolver.

9. **Seed `archetype` key kept** (plan: merge into `archetypes`): the main file and the archetype file hold identical arrays for all 83 characters, so there was nothing to merge; the key name the loader already reads is kept. Four synergy pairs were reordered into canonical order; no duplicates, no conflicting costs. Achievements: enum values as `{ tag }` objects, `undefined` → `null`, criteria nested per achievement.

## Findings and deviations

1. **New arguments are optional** on `create_lobby`, `update_lobby_settings`, presets and `update_tournament.lobbyPresetId` (required ones would have broken the frozen S4 fixtures and the S5 preset arguments). Clients may still pass every field.
2. **`lineupFormat = Thirds` is accepted without the 12-character check**: no schema field states characters per team (every draft sequence fields 8; `teamSize` counts players). **S7** owns the rule with the lineup groups.
3. **`Lobby.name` defaults to empty**, not "<host>'s lobby", which would leak the host in an anonymous lobby; **S9**'s `view_lobby_browser` labels empty names.
4. **Tournament lobbies reject explicit changes** of the three locked series fields (#9 done-when); the older D-65 locked fields still silently keep their value. Passing the current value is accepted.
5. **Bo1 head start is forced to None**, not rejected (#6 wording).
6. **Auto-ban with no legal character records the existing SKIP sentinel**, not EMPTY.
7. **Head start survives the Scoring recount** (`postDraft.ts`): not in the brief, required for #7's done-when; without it the win recount wiped the seeded game.
8. **Single-account rating uses the stored `HsrAccount.accountRating`**, so it equals the pre-S6 number exactly; two or more accounts use the merged union.
9. **`delete_my_account` lobby guard** mirrors `ensureNotInLobby`: AwaitingResult / Finished lobbies and voluntarily-left seats do not block.
10. **`update_tournament` validates `winnerAdvantage` against the stored `grandFinalBestOf`**; that argument itself arrives in S8.
11. **`docs/match-results/contract.md` still documents the old MAX rule** (outside the S6 doc list): **S7** updates it with the scoring contract.
12. **Inline breaker fixture** lowers the threshold to 20 through `admin_update_abuse_config` so the test builds 21 guests, not 51; the seeded default is 50 (A58).
13. Biome formatting not applied (lint gate is M3).

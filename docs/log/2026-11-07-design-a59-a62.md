## Audit: stage guards and confirmation paths (input for the S7b brief)

**Facts found.** Score entry (`record_group_scores`, `set_score_adjustment`) has no stage check today, only "current game" + liveness + authority. The confirmation flags live on `MatchResultRecord` (series level), set by `confirm_match_scores`; games are never confirmed. `advance_stage` Equipping→Scoring checks nothing ("host can force", D-58); its Scoring branch recomputes the current game and moves to BetweenGames / AwaitingResult. Ranked submissions land in `Submitted` and only the admin force-finalize moves them on; Casual auto-validates (D-04 / D-37); concedes validate themselves. `place_bid` and `nominate_character` perform no ownership check. Both Auction sale paths (`pass_bid`, `timer_expiry_auction`) copy the Nominate eidolon. Account selection is allowed only in Waiting and BetweenGames, so ownership is frozen during a game.

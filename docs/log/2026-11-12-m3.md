# M3: Vite shell (2026-11-12)

## Goal

`web/` becomes a working Vite + React 18 + TypeScript app with design tokens, base and custom-media CSS, self-hosted fonts, the standby page ported from `design/mockups/standby.html`, and a 404 page. No router (M4), no database connection (M6), no hosting config (M7), no service worker work (M10).

## Deviations and open points

- The old plan's M3 check "logs the identity hex from test1" moved to M6; M3 only resolves and logs the target name in dev.
- `fonts.css` is a fourth global stylesheet: the font packages name their families differently from the tokens and offer no per-subset entry points.
- The token file invents two names, `--radius-panel` and `--radius-modal`, for values given in `DESIGN.md` 11.3.
- Root `npm run build` needs `VITE_STDB_TARGET` in the environment; to be set per Vercel environment at M7/M8.
- For M4: `IpcButton` and the brand link render plain anchors and `StandbyPage` reads `window.location.search`; both move to the router.
- Before the first spinner: the reduced-motion guard stops every animation after one run, with no opt-out.
- Only the latin font subset is loaded. Safari lacks the font metric override descriptors (collected for the later Safari pass).
- Open with the user: 404 artwork; CTA height (mockup 52 and 46 px, `DESIGN.md` says 56); headline size step at 560; 404 wording; brand word colour over the art.
- Whole-repo `npm run lint` still reports pre-existing findings outside the new files (unchanged by this step).

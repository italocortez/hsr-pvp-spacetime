## Findings and hand-offs

- **L34 reverses a contract scenario.** The triage row said the contract allows undoing the last Auction ban; the contract's S4 entry (F9) refused it and superseded the older scenario, because no budget rollback existed. As built, undo works only before the first nomination, where nothing has been bought, and the reviewer confirmed the state is restored exactly. Reported to the user, who approved the item on the wrong premise; recommendation: keep. The contract carries a superseded marker and a Phase History row.
- **L51** drops the "snapshot authority" of the S10h review fix pass (a referee whose lobby row is gone could still finalize). It came from a review note, not from a decision row. With no lobby row only staff finalize.
- **L40, Classic**: Classic picks never move the session budgets, so a Classic match ended during the draft archives 0; a finished Classic match archives the light-cone and eidolon spend, as before. The real roster cost is in the archived Pick steps and in `MatchLineupHistory.rosterCost`: the history page reads it there.
- **L4**: `view_my_mmr_history` can list a rating row whose match no longer opens.
- **L22**: a preset kept for an unfinished tournament is not removed later and becomes Admin-only; another user's preset pointing at a deleted unpublished set is left dangling (`delete_cost_set` has the same gap). Deletion scans `Lobby` and `Tournament` once per unpublished set.
- **L42**: an empty character name is now stored as no filter (beyond the item's wording; without it the checker matched nothing).
- Test gaps left (review F5): an away referee and a caller with no member row on `finalize_match_result`.
- The `update_elo_config` flow text in `docs/mmr/architecture.md` uses old field names; noted in the file, not rewritten.
- Skill pass, left for the user: long history sections (the 2.2.0 guard story, bug lists for 2.1.0 and 2.6.1) could be removed; `docs/frontend/component-hygiene.md` still prescribes Next.js folders and should be rewritten at M3.
- Deviations from a decision row: none. A122(9) departs from the S4 contract entry as described above.

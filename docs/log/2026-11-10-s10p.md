## The shuffle

Fisher-Yates over a copy. For i = n-1 down to 1: `j = floor(murmur3Words([tsLo, tsHi, domain, id, i]) * (i+1) / 2^32)`, swap i and j. Domain words: `SEED` (bracket seeding, tournament id), `SWAP` (RandomSwap, lobby id), `TEAM` (team formation, tournament id). Input orders unchanged (team id, join sequence, user id). Each step is uniform within (i+1)/2^32. The whole order is a function of one 32-bit state, so at most 2^32 orders are reachable per site and id: every order up to n = 12, a subset from n = 13. A timestamp-seeded generator had the same limit.

Reviewer's own measurement (adversarial timestamps, three domains, ids 1 to 3):

| Measurement | Sample per cell | Max deviation from ideal |
|---|---|---|
| n = 2 orders | 1,200,000 | 0.20% |
| n = 3 orders | 1,200,000 | 0.68% |
| n = 4, all 24 orders present | 1,200,000 | 2.02% |
| n = 8 first position / position matrix / adjacency | 800,000 | 0.62% / 0.81% / 1.10% |
| n = 16 first position / position matrix / adjacency | 800,000 | 1.29% / 1.63% / 1.62% |

No correlation between the three sites, between adjacent ids, or between consecutive microseconds.

# S14.2c: costs filter row on phones (2026-11-16)

## Goal

Stop the filter rows from jumping when a filter is picked on phones, and give the Clear button a fixed place and a red tint. Test task T-S14.2c. No backend change, nothing deployed.

## Decisions implemented

A187.

## What changed

- `web/src/pages/costs/CostsPage.tsx`, `CostsPage.module.css`: a grid at 560 px and below (search and Clear, elements, paths, role, Archetype and rarity in a pair wrapper that has no effect above 560 px); compact Clear on phones; red tint mixed from `--color-error`.
- `web/src/components/MultiSelectDropdown/`: the count badge is always rendered, empty and hidden from assistive technology until a pick.
- Tests: four new (one in `MultiSelectDropdown.test.tsx`, three in `CostsPage.test.tsx`); none changed or removed.
- `docs/frontend/pages.md`: "Filter row on phones (S14.2c)", one new row in the wording table.
